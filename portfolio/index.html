L'Écosystème AdhanBox

Du prototypage électronique de la carte mère aux applications mobiles et logicielles coordonnées pour les pratiquants et les mosquées.

Matériel & Firmware embarqué v1.4.0
AdhanBox (ESP32-S3)

Système embarqué autonome sur ESP32-S3. Conçu avec une horloge temps réel DS3231 (RTC) pour fonctionner hors-ligne. Il calcule localement les horaires ou se synchronise avec les horaires exacts d'une mosquée via l'API Mawaqit. Il gère la lecture audio par protocole série (DFPlayer Mini) et contrôle un ruban LED SK6812 via l'API NeoPixel selon plusieurs scénarios configurables (off, fixe, arc-en-ciel, respiration, bougie).

C++ / FreeRTOS Mawaqit API Sync mDNS / DNS Server BLE Provisioning MQTT Client

Mobile · Android & iOS v1.0.0
AdhanBox App (Flutter)

Application compagnon Flutter conçue pour simplifier la configuration matérielle. Grâce à la découverte mDNS locale, elle détecte le boîtier sur le réseau et propose une synchronisation en un seul clic : elle récupère les coordonnées GPS du smartphone et configure automatiquement la position (`set_location`), l'heure exacte du RTC DS3231 (`set_rtc_manual`), le fuseau horaire (`set_tz`), et lance une synchronisation immédiate des horaires Mawaqit de la mosquée.

Flutter / Dart mDNS Discovery REST API Client Location Service Riverpod State

Desktop · Windows App v1.1.0
Adhan Overlay (Electron)

Application de bureau pour Windows facilitant le rappel visuel et discret de la prière lors du travail sur ordinateur. Elle dessine un cadre lumineux et coloré transparent aux bords de l'écran sans jamais interrompre les clics ou la visibilité (transparent et cliquable à travers). Elle se connecte à l'AdhanBox locale via requêtes HTTP REST.

Electron / JS Transparent Windows Click-through API mDNS Scanner Node Native API

Interactive tactile kiosk v1.2.0
Adhan Kiosk (Borne Tactile)

Borne interactive développée en mode Kiosk plein écran sous Electron pour simplifier la collecte physique de dons à la Mosquée El-Hijra de Tarbes. Elle intègre un clavier numérique et des sélections rapides par campagnes configurables. Les transactions de dons validées sont enregistrées localement dans une base SQLite robuste et synchronisées de manière chiffrée vers l'administration.

Electron / SQLite Kiosk Mode Web API Multi-campaigns Sync protocol Tailored touch UI

Parcours

Mon cheminement de Maker

Comment je suis passé du routage d'un circuit imprimé au déploiement d'un écosystème d'applications interconnectées.

2024

Conception Électronique (PCB)

Conception et routage de la carte électronique d'AdhanBox dans KiCad. Intégration de l'ESP32-S3, routage d'un oscillateur RTC haute précision (DS3231) sur bus I2C, et intégration du contrôleur DFPlayer Mini avec isolation pour éviter les parasites audio.

Début 2025

Firmware C++ (Arduino/FreeRTOS)

Développement du firmware C++ embarqué. Mise en œuvre du protocole de calcul astronomique des horaires en local, gestion d'un serveur DNS captif pour la configuration et développement d'un serveur BLE (Bluetooth Low Energy) pour scanner les réseaux WiFi environnants.

Mi 2025

Applications Desktop & Tactile

Conception d'Adhan Overlay en Electron (Windows) pour un affichage discret, et programmation de la borne interactive Adhan Kiosk pour la Mosquée El-Hijra de Tarbes (collecte locale avec base de données SQLite).

2026

Application Mobile Flutter & API Mawaqit

Développement de l'application mobile en Flutter pour Android & iOS, avec refonte de l'interface pour la rendre simple et technophobe-friendly (synchro GPS/RTC/Timezone en un seul tap). Intégration de la synchronisation distante avec l'API Mawaqit.
