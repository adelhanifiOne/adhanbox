Mes Projets

Des solutions technologiques au service de la pratique religieuse quotidienne.

IoT · Embarqué · Arduino
AdhanBox

Système autonome de diffusion de l'adhan basé sur ESP32. Calcule les horaires de prière via géolocalisation WiFi, pilote un strip LED SK6812 de 150 LEDs et un DFPlayer Mini. Interface web de configuration intégrée accessible via point d'accès WiFi.

ESP32 C++ / Arduino WS2812 / SK6812 DFPlayer Mini RTC DS3231 WiFi / mDNS MQTT
GitHub
Mobile · iOS & Android
AdhanBox App

Application Flutter companion de l'AdhanBox. Découverte automatique via mDNS, configuration des horaires, contrôle du strip LED, synchronisation RTC/GPS et support MQTT. Interface élégante avec thème sombre/clair et animations fluides.

Flutter Dart Riverpod MQTT mDNS / Bonjour REST API Material 3
GitHub
Desktop · Windows · Electron
Adhan Overlay

Overlay Windows discret et subliminal pour les horaires de prière. Un cadre coloré s'affiche autour de l'écran sans jamais interrompre votre travail (cliquable à travers). Vert → entrée de prière, Orange → fin proche, Rouge → urgence. Géolocalisation automatique, 4 thèmes visuels.

Electron JavaScript adhan.js Windows System Tray Auto-updater Transparent overlay
GitHub Télécharger .exe
Desktop · Kiosk · Mosquée
Adhan Kiosk

Application borne interactive Electron pour la collecte de dons en mosquée. Interface tactile plein écran, sélection de montant prédéfini ou libre, affichage des horaires de prière, gestion de plusieurs campagnes. Déployée à la Mosquée El-Hijra de Tarbes.

Electron JavaScript Kiosk Mode adhan.js electron-store Tactile / Touch
